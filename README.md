# Полка — дневник кино, сериалов, книг и игр

Статическое PWA без сборки и сервера. Отмечайте просмотренное, ставьте оценки 1–10,
пишите мини-отзывы и сравнивайте вкусы с друзьями.

## Как это работает
- Данные хранятся в `localStorage` на вашем устройстве (никаких аккаунтов и серверов).
- **Друзья:** «Я → Поделиться полкой» даёт ссылку/код/файл со снимком вашей полки.
  Друг открывает ссылку (или вставляет код в «Друзья») — и видит совпадение вкусов,
  спорные оценки и то, что стоит посмотреть. Повторный обмен обновляет снимок.
- Совпадение считается по одинаковым названиям (тип + название без регистра и знаков):
  `100 − 11 × средняя разница оценок`.
- **Резервная копия:** «Я → Сохранить копию» — файл для переноса на другой телефон.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в корень содержимое этой папки.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`.

## Установка на телефон
- iPhone: Safari → «Поделиться» → «На экран “Домой”».
- Android: Chrome → меню → «Установить приложение».

## Обновление
После изменения файлов увеличьте `VERSION` в `sw.js` (`polka-v2`…), чтобы телефоны подтянули новую версию.

## Заметки
- Данные привязаны к адресу сайта: при смене домена/репозитория делайте резервную копию и восстанавливайте.
- iOS может очищать данные сайтов, которые долго не открывали, — делайте копии время от времени.
